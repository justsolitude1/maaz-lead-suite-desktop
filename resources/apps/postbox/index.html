How these numbers are counted

Lead and SMYKM daily counts start from the dashboard’s first run and track new records or newly added public bio context. The current directory contains — leads, including — with bio/context; its older rows have no discovery dates.

“Emails written” counts message records added to Postbox’s schedule queue on the selected date. Sent totals use successful Gmail delivery records. Replies are counted only when an incoming message is in a thread with a matching sent campaign email. All dates use Asia/Karachi.
